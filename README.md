# EduGenie – Google Gemini Powered Learning Assistant

This is a simple front-end demo for a college project.

## Demo
Open `index.html` in a browser.

## Gemini integration
This demo intentionally does not contain an API key. For a real Gemini-powered version, use a backend/serverless function and keep the Gemini API key on the server.

## Deploy
Upload the three files (`index.html`, `style.css`, `script.js`) to Netlify, Vercel, or GitHub Pages.
